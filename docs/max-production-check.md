# Обновление мини-приложения MAX на сервере

Репозиторий: `Sabidabi/hackathon-max.vk.company`. Бот для проверки: `https://max.ru/t540_hakaton_max_bot`. Ссылка на бота **не является** HTTPS-адресом веб-приложения, который прописан в настройках MAX.

## На сервере с Docker Compose

В каталоге проекта, где находится рабочий `.env`:

```bash
git pull --ff-only origin main
docker compose config --quiet
docker compose up -d --build frontend backend worker
docker compose ps
```

Команда пересобирает образы из новой версии кода. Один `git pull` не обновляет уже запущенный frontend-контейнер. Не заменяйте рабочий `.env` примером из репозитория.

В настройках этого бота на платформе MAX должен быть указан публичный **HTTPS URL веб-приложения** и включена кнопка запуска мини-приложения. В серверном `.env` проверьте без публикации значений: `APP_ENV=production`, `DEV_AUTH_ENABLED=false`, `MAX_BOT_USERNAME=t540_hakaton_max_bot`, `MAX_BOT_TOKEN` от того же бота и `PUBLIC_APP_URL` с тем же HTTPS-адресом. Если используется webhook, проверьте также его HTTPS-адрес и secret.

## Проверка после обновления

1. На публичном адресе `/api/v1/health/ready` должен быть успешный ответ, а `/api/v1/auth/bootstrap` должен показывать `max_auth_configured: true` и `development_auth: false`.
2. Закройте старое окно мини-приложения в MAX и откройте его через кнопку бота. В новом интерфейсе больше нет фразы «Откройте кабинет в MAX».
3. Если вход всё ещё не проходит, отправьте боту `/start` и нажмите **новую** кнопку в ответе: теперь бот посылает тип `open_app`. Старые сообщения с прежней кнопкой не изменятся.
4. Проверьте создание точки, публикацию меню и гостевую ссылку. Не передавайте в переписке `WebAppData`, bot token или полный URL с fragment после `#`.

Если после обновления появляется «MAX не подтвердил запуск», сервер получил данные, но отклонил подпись или срок. Если появляется «Нет данных для входа», клиент не получил `WebAppData`: проверьте URL и способ запуска в настройках бота. Доступ к серверу и публичный HTTPS-адрес пока не предоставлены, поэтому фактическая production-проверка остаётся открытой.
