# Демо-сценарий MVP «Синицы»

Команда `python -m app.demo_seed` создаёт тестовую «Кофейню Север» с двумя точками. Данные лежат в `backend/app/demo_data.py`. Фотографий в этом наборе нет; для проверки карточек с фото загрузите свои тестовые изображения.

Что появится после запуска:

| Что | Значение |
| --- | --- |
| Заведение | «Кофейня Север», администратор — локальный dev-пользователь (`DEV_MAX_USER_ID`), он же создатель |
| Точки | «Север на Петровском» (`/r/demo-sever`), «Север у парка» (`/r/demo-sever-park`) |
| Меню | «Основное» (Кофе, Не кофе, Выпечка) — на обеих точках; «Завтраки» — только на Петровском, 08:00–12:00 по Москве |
| Настройка | Латте: размеры 250/350 мл (190/230 ₽), обязательное молоко (Обычное по умолчанию, Овсяное +50 ₽, Миндальное +60 ₽), сироп до 2 шт.; Американо и Капучино с размерами |
| Стоп-лист | «Круассан» нет в наличии только на точке «Север у парка» |
| Публикация | оба меню и оформление опубликованы |

## Запуск

Docker: `docker compose up -d --build`, затем `docker compose exec backend python -m app.demo_seed`. Настройки окружения и проверка запуска описаны в [README](../README.md). Сид печатает адрес кабинета `…/manage/demo-sever/menu` и гостевые ссылки.

Вход в кабинет в браузере — dev-вход (`APP_ENV=development`, `DEV_AUTH_ENABLED=true`); в MAX вход идёт по подписанному `initData`, dev-вход там выключен.

## Сценарий (≈ 3 минуты)

1. **Лендинг** `/` в обычном браузере → «Открыть демо-меню» открывает `/r/demo-sever`.
2. **Гость** на `/r/demo-sever`: вкладки разделов, поиск. Откройте «Латте»: выберите «Овсяное» и «350 мл» — цена 280 ₽ считается сервером. «В мой выбор», затем «+» у «Эспрессо».
3. **«Мой выбор» → «Показать на кассе»**: крупная сводка 400 ₽ для кассира. Онлайн-оплаты нет — гость показывает выбор на кассе.
4. **Вторая точка** `/r/demo-sever-park`: «Круассан — нет в наличии» (стоп-лист этой точки), на Петровском он доступен.
5. **Кабинет** `/manage` (dev-вход) → меню «Основное» точки «Север на Петровском».
   - Стоп-лист: выключите «Круассан» — гости этой точки видят «Нет в наличии» сразу, без публикации; «Отменить» в тосте возвращает.
   - Правка: в строке «Позиция и цена» раздела «Кофе» введите `Раф 250` и Enter — черновик сохранится.
   - Публикация: «Опубликовать изменения» → «Что изменится» → «Опубликовать в 2 точках»; «Раф» появился у гостей обеих точек.
6. **Ещё → QR и ссылка**: QR точки и ссылка `/r/demo-sever`, «Скачать для печати A6».
7. **Новая точка**: переключатель точки → «Новая точка» → название и адрес → «Создать точку». Меню «Основное» назначается сразу, у точки своя ссылка и QR.
8. **Ещё → Администраторы → «Пригласить администратора»**: ссылка-приглашение. Сообщения никому не отправляются — ссылку передают сами.
9. **Главная** `/home`: «Мои заведения» → «Кофейня Север».

Автоматическая проверка основного пути — `npm run test:live` (см. `README.md`). Для прогона в MAX используйте [чек-лист](max-production-check.md).

## `npm run demo`

`cd frontend && npm run demo` запускает локальную витрину без базы на точке `test-point`. Для показа с настоящим API используйте сид выше.
