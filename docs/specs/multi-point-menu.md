# Несколько точек и библиотека меню

Статус: реализуемый пакет, 26.09.2026. Метод работы: спецификация → план → задачи → проверка, по [Spec Kit](https://github.com/github/spec-kit/blob/main/spec-driven.md). Это документация проекта, не установленный CLI.

## Спецификация

Владелец создаёт несколько точек и открывает каждую по своей ссылке `/manage/{public_id}` после серверного входа. Редактор/управляющий видит только назначенные точки. Черновик и опубликованная версия относятся к одной точке. Библиотека содержит опубликованные и архивные версии всех точек владельца. Копирование создаёт независимый черновик и копии фотографий, требует актуальной ревизии и не публикует автоматически. Массовый стоп-лист меняет выбранные черновики атомарно и отклоняет неоднозначное сопоставление товара. Приглашение доступно лишь целевому MAX ID, одноразовое и действует 24 часа.

## План и связи компонентов

`MAX initData → server auth → User → RestaurantMember → Restaurant → Menu → MenuVersion → MenuSection → MenuItem`. Ссылка кабинета и `startapp` выбирают точку, но не дают права. Приглашение хранит только хеш токена и целевой MAX ID. При копировании исходная `MenuVersion` остаётся неизменной; целевой `draft` блокируется и проверяется по ревизии. Массовое наличие блокирует меню в стабильном порядке, проверяет все ревизии, затем меняет позиции одной транзакцией.

## Задачи и приёмка

- [x] Снять запрет на вторую точку; добавить переключение и ссылку кабинета. Проверка: владелец создаёт две точки, сотрудник видит одну.
- [x] Библиотека опубликованных версий и копирование в черновик. Проверка: чужая версия недоступна, повтор с прежней ревизией даёт 409.
- [x] Массовое наличие по выбранным точкам. Проверка: обновляются только черновики, повтор с прежней ревизией даёт 409.
- [x] Приглашение по MAX ID, принятие, смена роли и отзыв. Проверка: чужой ID даёт 403, повторное принятие невозможно, отзыв закрывает доступ.
- [ ] Проверить ссылку `startapp=inv_...` и команду `/id` в реальном MAX после развёртывания.
- [ ] Проверить мобильный UX на реальных меню нескольких заведений и собрать замечания.

Ограничение: это библиотека версий, а не общий каталог с автоматической синхронизацией; переименование позиции нарушает сопоставление для массового наличия, поэтому сервер отклоняет запрос до любых изменений.
