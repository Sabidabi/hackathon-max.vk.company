# Фирменный стиль «Синицы»

Основные правила и примеры собраны в [брендбуке](Sinitsa-Brandbook-v1.pdf). Для интерфейса используйте актуальные SVG из каталога `logos/svg/`.

## Состав

- `logos/svg/` — знак в синем, тёмном и белом цветах; горизонтальные логотипы; иконка приложения. Текст логотипов переведён в контуры, шрифт для открытия не нужен.
- `logos/png/` — прозрачные PNG логотипов; иконки от 16 до 1024 px. Белые версии смотрите на тёмном фоне.
- `reference/approved-concept.png` — первоначальный эскиз.
- `guidelines/BRAND_RULES.md` — правила для дизайнеров и разработчиков.
- `tokens/` — CSS и JSON для разработчика. Эти файлы не подключены к приложению автоматически.
- `source/` — исходные версии и геометрия знака. Для продукта берите файлы из `logos/`.

## Какой файл брать

| Задача | Файл |
| --- | --- |
| Аватар / приложение | `logos/svg/sinitsa-app-icon.svg` или PNG нужного размера |
| Светлый фон | `logos/svg/sinitsa-lockup-blue.svg` |
| Тёмный фон | `logos/svg/sinitsa-lockup-white.svg` |
| Один цвет | `logos/svg/sinitsa-lockup-black.svg` |
| Только птица | `logos/svg/sinitsa-symbol-blue.svg` |

Знак выровнен по оптическому центру. PNG сделаны из актуальных SVG; прежние файлы сохранены в `source/original-v1/`. Иллюстрации в PDF показывают раннюю версию центровки, поэтому для новых макетов используйте SVG из `logos/svg/`.

Цвета рассчитаны на экранное использование в sRGB. Для печати понадобится отдельная подготовка. Название и знак также требуют проверки перед массовым коммерческим использованием.
