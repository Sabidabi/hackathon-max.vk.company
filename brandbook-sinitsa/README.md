# Синица — брендбук v1.0

Откройте **Sinitsa-Brandbook-v1.pdf**: 10 страниц правил и примеров.

## Состав

- `logos/svg/` — знак в синем, тёмном и белом цветах; горизонтальные логотипы; иконка приложения. Текст логотипов переведён в контуры, шрифт для открытия не нужен.
- `logos/png/` — прозрачные PNG логотипов; иконки от 16 до 1024 px. Белые версии смотрите на тёмном фоне.
- `reference/approved-concept.png` — исходный выбранный концепт из переписки.
- `guidelines/BRAND_RULES.md` — правила бренда и инструкция для ИИ.
- `tokens/` — CSS и JSON для разработчика. Эти файлы не подключены к приложению автоматически.
- `source/` — геометрия знака и контуры букв в JSON; основные редактируемые исходники находятся в `logos/svg/`.

## Какой файл брать

| Задача | Файл |
| --- | --- |
| Аватар / приложение | `logos/svg/sinitsa-app-icon.svg` или PNG нужного размера |
| Светлый фон | `logos/svg/sinitsa-lockup-blue.svg` |
| Тёмный фон | `logos/svg/sinitsa-lockup-white.svg` |
| Один цвет | `logos/svg/sinitsa-lockup-black.svg` |
| Только птица | `logos/svg/sinitsa-symbol-blue.svg` |

SVG реконструирован по растровому концепту, а не автоматически трассирован. Формы и надпись немного нормализованы для единого набора. Предпросмотр SVG/PNG — источник истины для применения; исходный концепт сохранён отдельно. Тёмный вариант — #151821, белый — #FFFFFF. Файлы предназначены прежде всего для экранов в sRGB; CMYK и типографский профиль не утверждены.

Основной шрифт документа и рекомендованный системный шрифт интерфейса — Arial. Шрифтовые файлы не распространяются в комплекте. Перед массовым запуском отдельная проверка уникальности названия и знака остаётся задачей владельца: текущая стилистика намеренно близка к референсу Twitter, юридическая проверка не проводилась.

Комплект сохранён локально; изменения в приложение не внесены, коммита и публикации нет.

## Изменения v1.0.1 (28.09.2026) — центровка знака

Силуэт птицы и контуры надписи не менялись, изменены только положение и поля:

- `sinitsa-app-icon.svg`: центр масс птицы поставлен по горизонтальному центру плитки и на 4 px (из 512) выше геометрического центра — оптический центр. Поля: 80/83 по бокам, 132/144 сверху/снизу (было 61/102 и 109/167).
- `sinitsa-symbol-*.svg`: птица центрирована в квадрате 512 по центру масс (было смещение ≈ 47 px влево).
- `sinitsa-lockup-*.svg`: центр масс птицы выровнен по середине строчных букв, зазор клюв → «с» ≈ 0,55 высоты строчных, поля со всех сторон = ¼ видимой высоты (правило брендбука). Новый viewBox `637.36 × 141.58`, PNG `1320 × 293`.
- Все PNG пересобраны из исправленных SVG (рендер Chromium/Edge, прозрачный фон).
- Исходные версии сохранены в `source/original-v1/`. PDF-брендбук не пересобирался — иллюстрации в нём показывают прежнее положение.
